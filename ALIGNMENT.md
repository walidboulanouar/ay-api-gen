Worth a `sheal learn add` — not a handbook gap, an operator error, logged so it doesn't repeat.)
- **Commit messages that say what changed and why (`github.md`).** Every commit in this repo's history includes a body explaining the *why*, not just the diff — matches the standard.
- **pin-guard pre-flight (`pin-guard.md`: "Run it FIRST in any repo with a package.json").** Followed every session via the global `~/.claude/CLAUDE.md` rule — `python3 ~/.claude/skills/pin-guard/scripts/scan.py .` run before any work, checked again this session. Currently clean except 2 pre-existing, already-documented findings (unpinned `npx ay-api-gen` in `regen-apis.yml`, blocked on the npm-publish decision; an `.npmrc` `ignore-scripts` team-decision note). This is an engineer-session habit per the handbook's own framing, not a per-repo config file — nothing to add to this repo's `CLAUDE.md` to be "more aligned."
- **CI exists and gates PRs (`github.md`: "GitHub Actions is the test gate, not an afterthought... Wire Vitest and pytest into Actions on day one").** `.github/workflows/ci.yml` runs on every push/PR to `main`/`master`, matrix-tested on Node 20 and 22. This is real, not a stub.

## Gap found and fixed

- **CI runs unit tests only — the 120-test integration suite was never wired in.** `.github/workflows/ci.yml` ran `node test/run.js` (166 unit tests as of this session) but never `node test/integration-cli.js` — the real-child-process, real-MCP-protocol suite that's actually where most of this project's meaningful coverage lives (CLI commands, the StreamableHTTP transport, response caching, rate limiting, file locking under concurrency). This directly contradicts the handbook's own standard: *"a PR that hasn't gone green doesn't merge"* — a PR could go fully green in CI while its integration-level behavior was silently unchecked. `package.json` already had a `test:all` script (`npm run test && npm run test:integration`) that nobody had pointed CI at — a "buy before build" fix, not new tooling. Implemented in this session's PR: swap `ci.yml`'s `node test/run.js` step for `npm run test:all`.
