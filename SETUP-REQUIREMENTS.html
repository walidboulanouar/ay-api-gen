2. MCP Servers to Install

MCP servers give Claude Code direct access to external services. Install these so the AI agent can autonomously manage deployments and packages.
GitHub MCP Built-in

Already available in Claude Code via gh CLI.

ay-api-gen (self) Connected

Petstore MCP server registered in settings.local.json for testing.

For the Managed Infra version (future)

# When building the managed platform, these will be needed:

# Supabase — user accounts, API registry database
claude mcp add supabase npx -- -y @anthropic-ai/mcp-server-supabase --access-token YOUR_TOKEN --project-id YOUR_PROJECT

# Stripe — billing for managed MCP hosting
claude mcp add stripe npx -- -y @anthropic-ai/mcp-server-stripe --api-key YOUR_STRIPE_KEY

# Vercel — frontend dashboard deployment
# (use vercel CLI instead — no MCP server needed)

4. Environment Variables

Create a .env file in the project root. These are only needed for publishing and deployment — the core tool works without them.
VARIABLE REQUIRED PURPOSE STATUS
NPM_TOKEN For publish npm publish via GitHub Actions Missing
GITHUB_TOKEN Auto Auto-set by GitHub Actions Auto
FLY_API_TOKEN Optional Deploy to Fly.io Missing
API_KEY Per API Auth for generated MCP servers (per-API .env) Per API 
# .env (project root — for publishing)
NPM_TOKEN=npm_xxxxxxxxxxxx

5. Quick Setup Checklist

  • Node.js 22+ installed
  • npm installed
  • GitHub CLI authenticated
  • opensrc installed globally
  • ay-framework scaffolded
  • Docker installed
  • Git repo initialized
  • Pushed to GitHub
  • npm login (run npm login)
  • Set NPM_TOKEN in GitHub repo secrets
  • npm publish (run npm publish --access public)
  • CI/CD workflows created
  • Install flyctl (optional, for managed infra)
